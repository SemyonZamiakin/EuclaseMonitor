# Сделайте под себя: руководство по кастомизации Euclase Monitor

Всё, что вы видите в оверлее (фон, цвета, шрифты, расположение, какие числа показаны), берётся из **одного текстового файла**:
`skin.json`. Откройте его любым редактором, сохраните, и оверлей обновится **мгновенно**, без перезапуска. Если вы ошиблись,
оверлей продолжит показывать прежнюю версию, а трей скажет, что не так.

Каждый блок кода в этом руководстве автоматически проверяется настоящим загрузчиком скинов, поэтому его можно копировать как есть.

[English version](CUSTOMIZE.md)

---

## 1. Первое изменение за минуту

1. Правый клик по значку в трее → **Customize this skin...**
   Euclase Monitor скопирует скин в вашу папку (`%APPDATA%\EuclaseMonitor\skins\<имя>-mine`), переключится на копию
   и откроет `skin.json`. Оригинальные скины не изменяются никогда.
2. Найдите `"background"` и поменяйте цвет, например `"color": "#1b2a49cc"`.
3. Сохраните файл (Ctrl+S). Через мгновение оверлей изменится.

Чтобы **перетащить** оверлей в другое место: трей → снимите галочку **Click-through**, перетащите, поставьте галочку обратно.
Положение запоминается отдельно для каждого скина.

## 2. Как устроен скин

Скин это папка с файлом `skin.json` и, по желанию, картинками рядом:

```
my-skin/
  skin.json
  background.png     (любой png / jpg)
  logo.png
```

Самый маленький рабочий скин:

```json skin
{
  "name": "Hello",
  "window": { "width": 200, "height": 50 },
  "widgets": [
    { "type": "text", "x": 12, "y": 12, "text": "CPU {cpu.load:0}%", "color": "#ffffff" }
  ]
}
```

**Правила формата** (это JSON с несколькими удобствами):

- Комментарии разрешены: `// вот так` и `/* вот так */`.
- Запятая после последнего элемента не ошибка.
- Цвета: `"#RRGGBB"`, `"#RRGGBBAA"` (AA это непрозрачность: `ff` сплошной, `80` наполовину) или `"$имя"` (переменная, см. раздел 5).
- Все размеры и позиции в **единицах**: 1 единица = 1 пиксель при масштабе Windows 100%. Оверлей сам масштабируется на 4K-экранах
  и через `window.scale`.
- Точка `(0, 0)` это левый верхний угол оверлея.

## 3. Окно

```json skin
{
  "name": "Window demo",
  "window": {
    "width": 320,            // размер оверлея
    "height": 120,
    "anchor": "bottom-right", // top-left, top-center, top-right, center-left, center, center-right, bottom-left, bottom-center, bottom-right
    "margin": [20, 20],       // отступ от края экрана (x, y); или одно число для обоих
    "monitor": 0,             // 0 = основной монитор, 1 = следующий...
    "opacity": 0.9,           // 0.1 .. 1: делает прозрачным весь оверлей
    "scale": 1.0,             // 1.5 увеличивает всё на 50%
    "topmost": true,          // держаться поверх других окон
    "clickThrough": true      // щелчки мыши проходят сквозь оверлей в игру / окно под ним
  },
  "update": 1000,             // как часто обновляются числа, в миллисекундах (250 .. 10000)
  "widgets": []
}
```

Замечание: оверлей виден поверх обычных и безрамочных полноэкранных игр. Он не может появиться поверх игр с
**эксклюзивным** полноэкранным режимом: переключите игру в режим «в окне без рамки».

## 4. Фон: цвет, градиент, картинка

```json skin
{
  "name": "Backgrounds",
  "window": { "width": 300, "height": 100 },
  "background": {
    "gradient": { "from": "#0f2933ee", "to": "#2a1245ee", "angle": 60 },
    "radius": 24,
    "border": { "color": "#ffffff30", "width": 1 }
  },
  "widgets": []
}
```

- `"color": "#rrggbbaa"`: сплошной цвет. `transparent` или `aa` равное `00` убирает фон совсем.
- `"gradient": { "from", "to", "angle" }`: заменяет сплошной цвет (`angle` 0 = слева направо, 90 = сверху вниз).
- `"image": "bg.png"`: картинка из папки скина, рисуется **поверх** цвета. `"fit"`: `cover` (заполнить, обрезав края),
  `contain` (вписать целиком) или `stretch` (растянуть). `"imageOpacity": 0.5` пропускает цвет сквозь картинку: так проще всего
  сохранить читаемость текста на пёстрой картинке.
- `"radius"`: скругление углов. `0` = острые углы.

**Чтобы поставить свои обои:** скопируйте скин (раздел 1), положите картинку в папку и впишите её имя в `"image"`.
Картинку можно перезаписывать, пока Euclase Monitor работает: она подхватывается при сохранении.

## 5. Цвета один раз, везде: `vars`

Положите палитру в начало и используйте `$имя` везде. Чтобы перекрасить весь скин, правятся 3 строки.

```json skin
{
  "name": "Palette",
  "vars": { "text": "#f8fafc", "accent": "#2dd4bf", "danger": "#ff5d6c" },
  "window": { "width": 220, "height": 70 },
  "widgets": [
    { "type": "text", "x": 12, "y": 10, "text": "CPU {cpu.load:0}%", "color": "$text" },
    { "type": "bar", "x": 12, "y": 40, "w": 196, "h": 8, "radius": 4, "value": "cpu.load", "color": "$accent",
      "colors": [ { "above": 90, "color": "$danger" } ] }
  ]
}
```

## 6. Шрифты

Объявите шрифты один раз в `"fonts"` и ссылайтесь на них по имени. Подойдёт любой шрифт, установленный на ПК.
Если шрифта нет на чужом компьютере, будет использован Segoe UI.

```json skin
{
  "name": "Fonts",
  "fonts": {
    "main":  { "family": "Segoe UI", "size": 12 },
    "big":   { "family": "Consolas", "size": 30, "bold": true }
  },
  "window": { "width": 200, "height": 70 },
  "widgets": [
    { "type": "text", "x": 12, "y": 8,  "font": "big",  "text": "{cpu.load:0}%" },
    { "type": "text", "x": 12, "y": 48, "font": "main", "text": "{cpu.name}", "color": "#8fb3bc" }
  ]
}
```

`size` это высота текста в единицах. `main` используется всеми надписями, у которых не указан другой шрифт.

## 7. Виджеты: строительные блоки

Скин это список виджетов, они рисуются по порядку (следующие поверх предыдущих). Общее для всех: `type`, `x`, `y`,
`opacity` (0..1) и `visible` (см. раздел 10).

### text
Показывает текст с живыми числами. Значения пишутся в фигурных скобках: `{метрика}` или `{метрика:формат}`.

```json widgets
[
  { "type": "text", "x": 10, "y": 10, "text": "GPU {gpu.load:0}%  {gpu.temp:0}°C  {gpu.clock:mhz}", "color": "#99f6e4" },
  { "type": "text", "x": 10, "y": 34, "w": 180, "align": "right", "text": "↓ {net.down:rate}" },
  { "type": "text", "x": 0, "y": 0, "w": 200, "h": 100, "align": "center", "valign": "middle", "text": "centred in a box" }
]
```

Без `w`/`h` текст начинается в точке `x`/`y`. С `w` (и `h`) он живёт в рамке: используйте `align` (`left`, `center`, `right`)
и `valign` (`top`, `middle`, `bottom`); слишком длинный текст обрезается с «...». Чтобы вывести фигурную скобку как есть, пишите `{{` или `}}`.

### bar
Полоса прогресса из любого значения.

```json widgets
[
  { "type": "bar", "x": 10, "y": 10, "w": 180, "h": 10, "radius": 5, "value": "ram.used_pct", "min": 0, "max": 100,
    "color": "#7fb8c9", "colorTo": "#99f6e4", "track": "#ffffff1a" },
  { "type": "bar", "x": 10, "y": 30, "w": 12, "h": 60, "vertical": true, "value": "cpu.load", "color": "#2dd4bf" }
]
```

`colorTo` делает градиент вдоль полосы. `min`/`max` задают, что значит «пусто» и «полно». `track` это пустая часть.

### ring
Круговой индикатор. `w`/`h` задают размер (берётся меньшее), `thickness` толщину линии.
По умолчанию это шкала на 270° с разрывом снизу; меняйте `startAngle` и `sweep` для других форм
(`"startAngle": -90, "sweep": 360` это полный круг, начинающийся сверху).

```json widgets
[
  { "type": "ring", "x": 10, "y": 10, "w": 80, "h": 80, "thickness": 9, "value": "cpu.load", "color": "#2dd4bf" },
  { "type": "text", "x": 10, "y": 10, "w": 80, "h": 80, "align": "center", "valign": "middle", "text": "{cpu.load:0}" },
  { "type": "ring", "x": 110, "y": 10, "w": 80, "h": 80, "thickness": 6, "startAngle": -90, "sweep": 360, "value": "ram.used_pct", "color": "#7fb8c9" }
]
```

### graph
Линия истории последних N обновлений. Значением может быть любая метрика или выражение.

```json widgets
[
  { "type": "graph", "x": 10, "y": 10, "w": 200, "h": 50, "value": "gpu.load", "history": 60,
    "color": "#99f6e4", "fill": true, "lineWidth": 2, "track": "#00000040", "radius": 8 }
]
```

`history` это число точек (2..600). При `update: 1000` 60 точек = последняя минута.

### rect, line, image

```json widgets
[
  { "type": "rect", "x": 10, "y": 10, "w": 100, "h": 40, "radius": 10, "color": "#ffffff14", "border": "#ffffff30", "borderWidth": 1 },
  { "type": "rect", "x": 120, "y": 10, "w": 60, "h": 40, "radius": 10, "color": "#2dd4bf", "colorTo": "#99f6e4" },
  { "type": "line", "x": 10, "y": 60, "x2": 180, "y2": 60, "color": "#ffffff30", "lineWidth": 1 }
]
```

`image` рисует картинку из папки скина (`png`, `jpg`, `gif`, `bmp`): `{ "type": "image", "file": "logo.png", "x": 10, "y": 10, "w": 48, "h": 48, "fit": "contain" }`.
Из соображений безопасности картинки должны лежать **внутри папки скина**.

## 8. Цвета, реагирующие на числа: `colors`

Полосы, кольца и графики могут менять цвет в зависимости от значения. Перечислите пороги; побеждает наибольший из достигнутых.

```json widgets
[
  { "type": "ring", "x": 10, "y": 10, "w": 70, "h": 70, "thickness": 8, "value": "gpu.temp", "min": 30, "max": 100, "color": "#99f6e4",
    "colors": [ { "above": 70, "color": "#ffb454" }, { "above": 82, "color": "#ff5d6c" } ] }
]
```

Здесь кольцо голубое до 70 °C, оранжевое с 70 и красное с 82.

## 9. Повторения: `repeat` и `group`

`group` двигает несколько виджетов вместе. `repeat` делает копии шаблона. Внутри шаблона `$i` это номер копии, начиная с **0**,
а `$i1` начинается с **1**. `dx`/`dy` это шаг между копиями.

По тонкому столбику на каждое ядро CPU (16 потоков):

```json widgets
[
  { "type": "repeat", "count": 16, "x": 10, "y": 10, "dx": 14,
    "template": { "type": "bar", "w": 10, "h": 40, "vertical": true, "radius": 4, "value": "cpu.core$i.load", "color": "#2dd4bf" } }
]
```

Таблица из 4 самых активных программ:

```json widgets
[
  { "type": "repeat", "count": 4, "x": 0, "y": 10, "dy": 18,
    "template": { "type": "group", "children": [
      { "type": "text", "x": 10,  "w": 150, "text": "{proc.cpu$i1.name}" },
      { "type": "text", "x": 170, "w": 60, "align": "right", "color": "#2dd4bf", "text": "{proc.cpu$i1.cpu:1}%" }
    ] } }
]
```

## 10. Показывать только когда нужно: `visible`

`visible` это выражение. Виджет рисуется, только когда оно истинно (не 0 и не «n/a»).
Метрики, которых нет на ПК (например, нет видеокарты NVIDIA), равны «n/a», так что блок скрывается автоматически.

```json widgets
[
  { "type": "text", "x": 10, "y": 10, "text": "GPU {gpu.load:0}%", "visible": "gpu.count > 0" },
  { "type": "text", "x": 10, "y": 34, "text": "GPU is hot!", "color": "#ff5d6c", "visible": "gpu.temp >= 80" },
  { "type": "group", "x": 10, "y": 60, "visible": "net.down > 1000000", "children": [
      { "type": "text", "text": "Downloading: {net.down:rate}", "color": "#99f6e4" }
  ] }
]
```

## 11. Выражения и форматы

Везде, где ожидается значение (`value`, `visible` и внутри `{...}` в тексте), можно написать выражение:

| Вы пишете | Значение |
|---|---|
| `cpu.load` | метрика (полный список: [METRICS.md](METRICS.md)) |
| `ram.used_gb / ram.total_gb * 100` | арифметика: `+ - * / %` и скобки |
| `max(cpu.load, gpu.load)` | `min`, `max`, `clamp(x, lo, hi)`, `abs`, `round`, `floor`, `ceil` |
| `if(gpu.temp > 75, 1, 0)` | выбор по условию |
| `cpu.load > 80 && gpu.load > 80` | сравнения `< <= > >= == !=` и `&& \|\| !` |

В тексте **формат** добавляется после двоеточия: `{значение:формат}`

| Формат | Пример результата | Для чего |
|---|---|---|
| `0` `1` `2` `3` `4` | `42`, `42.4`, `42.37` | число знаков после запятой |
| `rate` | `2.50 MB/s` | байты в секунду (сеть) |
| `bytes` | `34.0 GB` | размеры в байтах |
| `mhz` | `4.70 GHz` | частоты в МГц |
| `uptime` | `1d 02:15` | секунды как дни / часы / минуты |
| `mbit` | `18.4 Mbit/s` | байты в секунду как мегабиты |
| (нет) | `7.5` / `42` | разумный автоматический выбор |

Отсутствующее или недоступное значение выводится как `n/a`, никогда не как сбой.

## 12. Рецепты

**Тонкая полоса сверху экрана**

```json skin
{
  "name": "Slim bar",
  "window": { "width": 700, "height": 26, "anchor": "top-center", "margin": [0, 0] },
  "background": { "color": "#000000b0", "radius": 0, "border": { "width": 0 } },
  "fonts": { "main": { "family": "Segoe UI", "size": 12 } },
  "widgets": [
    { "type": "text", "x": 0, "y": 0, "w": 700, "h": 26, "align": "center", "valign": "middle", "color": "#d6f5f0",
      "text": "CPU {cpu.load:0}%   GPU {gpu.load:0}% {gpu.temp:0}°C   RAM {ram.used_pct:0}%   ↓{net.down:rate}  ↑{net.up:rate}   {time.hm}" }
  ]
}
```

**Вертикальная боковая панель** (высокая и узкая, у левого края)

```json skin
{
  "name": "Sidebar",
  "window": { "width": 90, "height": 340, "anchor": "center-left", "margin": [10, 0] },
  "background": { "color": "#0a1f27c8", "radius": 18 },
  "widgets": [
    { "type": "ring", "x": 10, "y": 12,  "w": 70, "h": 70, "thickness": 8, "value": "cpu.load", "color": "#2dd4bf" },
    { "type": "text", "x": 10, "y": 12,  "w": 70, "h": 70, "align": "center", "valign": "middle", "text": "{cpu.load:0}" },
    { "type": "ring", "x": 10, "y": 98,  "w": 70, "h": 70, "thickness": 8, "value": "gpu.load", "color": "#99f6e4" },
    { "type": "text", "x": 10, "y": 98,  "w": 70, "h": 70, "align": "center", "valign": "middle", "text": "{gpu.load:0}" },
    { "type": "ring", "x": 10, "y": 184, "w": 70, "h": 70, "thickness": 8, "value": "ram.used_pct", "color": "#7fb8c9" },
    { "type": "text", "x": 10, "y": 184, "w": 70, "h": 70, "align": "center", "valign": "middle", "text": "{ram.used_pct:0}" },
    { "type": "text", "x": 0, "y": 280, "w": 90, "align": "center", "color": "#8fb3bc", "text": "{time.hm}" }
  ]
}
```

**Показывать полную панель, только пока видеокарта занята («игровой режим»)**: оберните всё в `group` с `"visible": "gpu.load > 30"`.

**Полностью прозрачный оверлей только с текстом**: `"background": { "color": "#00000000", "border": { "width": 0 } }`.

## 13. Файл настроек и горячая клавиша

`%APPDATA%\EuclaseMonitor\settings.json` (создаётся автоматически; правьте, пока приложение закрыто):

```json
{
  "skin": "glass",
  "visible": true,
  "hotkey": "ctrl+alt+f10",
  "export": { "enabled": false, "port": 8099, "lan": false }
}
```

- `hotkey`: показать/скрыть оверлей. Формат `ctrl+alt+f10`, `ctrl+shift+m`... (нужна хотя бы одна из клавиш ctrl/alt/shift/win).
  Если сочетание уже занято другой программой, трей сообщит об этом.
- `export`: крошечная локальная веб-страница с числами для ESP32 / SPI-дисплеев и скриптов, см. [EXPORT.md](EXPORT.md).

## 14. Если что-то не работает

- **Оверлей не изменился после сохранения.** Откройте меню трея → **Open log**. В последних строках написано, что именно не так,
  с номером строки и столбца для синтаксических ошибок, например `skin.json: line 12, col 5: expected ',' or '}'`.
- **Число показывает `n/a`.** Такой метрики нет на этом ПК (см. [METRICS.md](METRICS.md)) или в названии опечатка.
- **Моя картинка не появляется.** Файл должен лежать внутри папки скина; проверьте имя и расширение `png` / `jpg` в журнале.
- **Я всё сломал.** Скопируйте скин заново из встроенной папки (`skins\...` рядом с exe) или удалите свою папку `-mine` в
  `%APPDATA%\EuclaseMonitor\skins` и выберите исходный скин в меню трея.

## 15. Поделитесь своим скином

Скин это просто папка: заархивируйте и отправьте или создайте pull request, добавляющий его в `skins/` в репозитории.
Пожалуйста, используйте картинки, на которые у вас есть права или которые свободны для использования.

Неизвестные настройки игнорируются, поэтому скин, сделанный для более новой версии, всё равно загрузится в старой (части, которые она
не понимает, пропускаются и перечисляются в журнале).
